Атрибуты и фильтры

Category schema (attributes_{id}.json) — единственный источник истины для фильтров. AI только извлекает значение; каноны и бакеты задаются здесь. filters_{id}.json строится из schema + нормализованных товаров.

ID — числовой код раздела. Импорт принимает массив атрибутов или {"id":929,"attrs":[...]}.

Шаблон выгрузки

Кнопки «JSON v2» и «2 файла» после прогона отдают один и тот же формат заказчика: семь полей в карточке и checkbox-фасеты. «JSON v2» дополнительно кладёт categories_v2.json. Ниже — схема файлов, не живые данные прогона.

Два файлаproducts + filters

Имена: products_(id).json и filters_(id).json. Если в прогоне несколько разделов — (id) становится all. В файлы попадают только карточки с полными характеристиками.

Поля товара
id
SKU магазина; чисто цифровой — числом
name
Название как в каталоге, без правок
meta_keywords
7–9 фраз через запятую
description_html
4 абзаца, один список плюсов, 1–3 <strong>, без <h1>
annotation_html
Список точных характеристик: «Подпись: значение»
filters
Объект фасетов; значения всегда массивы (в т.ч. бакеты)
web_info
Отзыв или пустая строка — поле всегда на месте

Парсеры поиска

Когда у карточки нет описания, сервер ищет ту же модель в сети по названию товара. Сначала Yandex Search API (официальный Cloud v2), затем свой URL, DuckDuckGo и запасные HTML-движки. Страница принимается, если на ней есть артикул или опознавательные слова имени.

Yandex Search API
Нужны API-ключ (scope yc.search-api.execute) и Folder ID каталога с ролью search-api.editor. Ключ остаётся на сервере. «Проверить работу» ходит в Cloud по полям на этой странице — сохранять не обязательно. Без ключа или folder поиск идёт дальше — свой URL, затем DuckDuckGo.

Шаблон выгрузки

Ключи JSON — поля файла. При выгрузке примеры заменяются живыми данными, {{id}} и другие плейсхолдеры подставляются из карточки. Сохраните — следующая выгрузка «2 файла» / «JSON v2» пойдёт с этими шаблонами. Пустой редактор или совпадение со встроенным ничего лишнего в файл не пишет.

Два файлаproducts + filters

Имена: products_(id).json и filters_(id).json. Если в прогоне несколько разделов — (id) становится all. В файлы попадают только карточки с полными характеристиками.

Поля товара
id
SKU магазина; чисто цифровой — числом. Название в выгрузке не дублируется: сопоставление по id
meta_keywords
7–9 фраз через запятую
description_html
4 абзаца, один список плюсов, 1–3 <strong>, без <h1>
annotation_html
Список точных характеристик: «Подпись: значение»
filters
Объект фасетов; значения всегда массивы (в т.ч. бакеты)
web_info
Отзыв или пустая строка — поле всегда на месте
products_(id).json встроенный
filters_(id).json встроенный
JSON v2+ categories
